# wakuwaku（仮：わくわく農園）

どうぶつの森風の農業スローライフゲーム × 高齢者の服薬管理・見守り。
現実の服薬・運動が、ゲーム内の畑を育てる「水」や「肥料」になる。家族はゲームの中で遊びに行く形で自然に見守れる。

- クライアント: Flutter（Flame）
- サーバー: 専用APIサーバー（初期案: Dart/Serverpod + PostgreSQL on GCP）
