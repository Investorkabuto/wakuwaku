# 02. 要件定義

> ステータス: ドラフト v0.1 / 2026-10-16
> 優先度: **M** = MVP必須 / **S** = MVP後すぐ / **C** = 将来検討

## 1. 用語

| 用語 | 意味 |
|---|---|
| ユーザー | アプリを使う人全般 |
| 見守られる人 | 家族グループで見守り対象になっているユーザー（主に高齢者） |
| 見守る人 | 見守りパネルを閲覧できる家族ユーザー |
| 家族グループ | 招待で作るクローズドなグループ。見守り・交流の単位 |
| タスク | 服薬・運動・予定など、現実の行動の記録単位 |
| 恵み | タスク完了で得られるゲーム内リソース（水・肥料・種など） |

## 2. 機能要件

### 2.1 アカウント・オンボーディング

| ID | 要件 | 優先 |
|---|---|---|
| ACC-01 | 電話番号SMS / Apple / Google でログインできる | M |
| ACC-02 | 家族が招待QRコードを発行し、高齢者端末で読み取るだけで初期設定〜家族参加が完了する（代行セットアップ） | M |
| ACC-03 | 初回起動時に「やさしいモード / ふつうモード」を選べる（後から変更可） | M |
| ACC-04 | 機種変更時のデータ引き継ぎ（アカウント紐づけ） | M |
| ACC-05 | アカウント削除・データ削除の申請ができる | M |

### 2.2 プライベートタスク管理

#### 服薬管理

| ID | 要件 | 優先 |
|---|---|---|
| MED-01 | 薬を登録できる（名前、写真、1回量、服用タイミング：朝/昼/夕/寝る前/時刻指定、曜日・隔日） | M |
| MED-02 | 薬の写真を撮って登録できる（名前入力が苦手な人向け。写真が主、名前は任意） | M |
| MED-03 | 服薬時刻にローカル通知でリマインド。**オフラインでも鳴る** | M |
| MED-04 | 通知から1タップ／アプリ内の大ボタンで「のんだ」を記録 | M |
| MED-05 | 同じ回の二重記録時は「さっき記録済みです。本当にもう一度？」と確認（飲み過ぎ防止） | M |
| MED-06 | 未記録時の再通知（例：30分後、60分後。回数・間隔を設定可） | M |
| MED-07 | 服薬カレンダー（記録の履歴を日/週/月で表示） | M |
| MED-08 | 家族が見守られる人の薬を代理で登録・編集できる（本人の許可設定時のみ） | M |
| MED-09 | 残薬数の管理と「残りわずか」通知 | S |
| MED-10 | 処方箋・お薬手帳のQRコード（JAHIS形式）読み取りで一括登録 | C |
| MED-11 | 「のまなかった（スキップ）」理由の記録（体調不良など） | S |

#### 運動・その他タスク

| ID | 要件 | 優先 |
|---|---|---|
| EXE-01 | 歩数を HealthKit / Health Connect から自動取得 | M |
| EXE-02 | 体操・ストレッチなどの運動タスクを登録・完了チェック | M |
| EXE-03 | ゲーム内「ラジオ体操風」の簡単な体操動画/ガイド（オリジナル） | S |
| TSK-01 | 汎用タスク（予定・家事・通院など）の登録、繰り返し設定、リマインド | M |
| TSK-02 | 体調の簡単な記録（顔アイコン5段階：元気〜つらい） | S |
| TSK-03 | 血圧・体重などのバイタル記録（手入力 / ヘルスケア連携） | C |

#### 共通ルール
- タスク記録は**医療的判断を一切しない**（用量計算・飲み合わせ・診断をしない）。
- 各タスクの「家族への共有可否」を本人が個別に設定できる。

### 2.3 ゲーム（農業×村暮らし）

| ID | 要件 | 優先 |
|---|---|---|
| GAM-01 | 自分の農園（畑・家・庭）を持ち、種まき→水やり→収穫ができる | M |
| GAM-02 | タスク完了で「恵み」を獲得：服薬→水、運動→肥料、汎用タスク→種/素材（配分はバランス調整可能なサーバー設定） | M |
| GAM-03 | 作物は**枯れない**。放置すると成長が止まるだけ | M |
| GAM-04 | 現実の時刻・季節と連動した昼夜・季節作物 | M |
| GAM-05 | どうぶつNPC住民との会話。服薬時間には住民がやさしく声をかける | M |
| GAM-06 | 収穫物の売却・ゲーム内通貨で家具・服・種を購入 | M |
| GAM-07 | 家・庭の模様替え（家具配置） | S |
| GAM-08 | 料理（収穫物を組み合わせる） | S |
| GAM-09 | 図鑑（作物・住民・家具コレクション） | S |
| GAM-10 | 季節イベント（お花見、夏祭り、収穫祭、お正月など） | S |
| GAM-11 | やさしいモードでは自動移動・ワンタップ作業で全ての基本操作ができる | M |
| GAM-12 | タスクを使わない一般ユーザーにも、ゲーム内行動だけで恵みを得られる代替手段がある（ただし控えめ） | M |
| GAM-13 | ミニゲーム（脳トレ要素：記憶・計算・並べ替えを農作業風に） | C |

### 2.4 交流（ユーザー同士・家族）

| ID | 要件 | 優先 |
|---|---|---|
| SOC-01 | 家族グループの作成・招待（QR/招待リンク） | M |
| SOC-02 | 家族・フレンドの農園を訪問できる（非同期：相手がオフラインでも訪問可） | M |
| SOC-03 | 訪問先で水やりのお手伝い、プレゼント（作物・家具）を置ける | M |
| SOC-04 | スタンプ・定型文メッセージ（「げんき？」「ありがとう」など） | M |
| SOC-05 | 家族グループ内の自由チャット（テキスト・音声メッセージ） | S |
| SOC-06 | 家族共同の「みんなの畑」（共同で育てる） | S |
| SOC-07 | フレンド申請（フレンドコード交換制。検索で見知らぬ人に見つからない） | S |
| SOC-08 | リアルタイム同時訪問（同じ画面に複数人のアバター） | C |
| SOC-09 | 公開広場（一般ユーザー同士。定型文・スタンプのみ、やさしいモードではデフォルト非表示） | C |
| SOC-10 | ブロック・通報機能 | M（SOC-07と同時） |

### 2.5 見守り

| ID | 要件 | 優先 |
|---|---|---|
| WAT-01 | 見守る人向け「見守りパネル」：今日の服薬状況、最終アクティブ時刻、歩数、体調アイコン | M |
| WAT-02 | 見守りは**本人の同意制**。共有する項目（服薬/歩数/体調/最終ログイン）を本人が選べる。同意画面は家族にも本人にも分かりやすく | M |
| WAT-03 | 服薬未記録が一定時間続いたら見守る人へ通知（例：予定時刻+2時間）。閾値は家族が設定 | M |
| WAT-04 | 長時間無操作アラート（例：24時間アプリ操作・歩数ともにゼロ）を見守る人へ通知 | M |
| WAT-05 | 本人からの「こまった」ボタン（家族に即通知＋電話発信ショートカット） | S |
| WAT-06 | 週次サマリー（家族へ「今週のおばあちゃんの農園」レポート：服薬率・収穫・訪問） | S |
| WAT-07 | 見守る人から「電話する」「スタンプを送る」がワンタップでできる | M |
| WAT-08 | 見守りは「監視」に見えないUI表現（例：“ハナさんの農園は今日も元気です”） | M |
| WAT-09 | 緊急時の注意書き：本アプリは緊急通報サービスではない旨の明示 | M |

### 2.6 通知

| ID | 要件 | 優先 |
|---|---|---|
| NTF-01 | 服薬・タスクのリマインドは端末ローカル通知（サーバー不通でも動作） | M |
| NTF-02 | 見守りアラート・交流通知はサーバープッシュ（FCM/APNs） | M |
| NTF-03 | 通知の種類別ON/OFF、おやすみ時間帯設定 | M |
| NTF-04 | 通知音・読み上げ（住民キャラの声で「お薬の時間ですよ」） | S |

### 2.7 運営・管理

| ID | 要件 | 優先 |
|---|---|---|
| ADM-01 | 管理画面：ユーザー検索、通報対応、アカウント停止 | M |
| ADM-02 | ゲームバランス（恵みの配分、作物成長時間、ショップ商品）のサーバー側マスタ管理 | M |
| ADM-03 | お知らせ・イベント配信 | S |
| ADM-04 | 問い合わせ対応（家族からの代理問い合わせ含む） | S |
| ADM-05 | 法人向けダッシュボード（施設が複数利用者を見守り） | C |

## 3. 非機能要件

### 3.1 アクセシビリティ（高齢者対応）

- タップ領域 **最小 56dp**（やさしいモード）、48dp（ふつうモード）
- 文字サイズ: やさしいモード最小20sp、OS文字サイズ設定に追従
- コントラスト比 WCAG 2.2 AA 以上（主要ボタンは AAA 目標）
- 色だけで情報を伝えない（アイコン＋文字併用）
- 画面内テキストの読み上げ（TTS）、VoiceOver / TalkBack 対応
- 誤操作防止: 削除・送信など重要操作は確認ダイアログ、長押し・スワイプ必須の操作を作らない（やさしいモード）
- 1画面1目的、戻るボタンを常に同じ位置に
- 高齢ユーザーでのユーザビリティテストを各フェーズで実施

### 3.2 性能

| 項目 | 目標 |
|---|---|
| 対応端末 | iOS 16+ / Android 9+（2〜3年前の中価格帯端末で快適に動作） |
| 起動時間 | コールドスタート 3秒以内（中位端末） |
| 描画 | 農園画面 30fps 以上を維持、省電力モード時は描画簡略化 |
| アプリサイズ | 初回DL 150MB以下、追加アセットは差分DL |
| API応答 | p95 300ms 以内 |
| 通知遅延 | 見守りアラートは条件成立から5分以内に送信 |

### 3.3 可用性・信頼性

- **オフラインファースト**: 服薬記録・リマインド・農作業はオフラインで動作し、復帰時に同期
- 同期の競合解決ルールを定義（タスク記録は追記型で競合させない）
- サーバー稼働率 99.5% 以上（見守りアラート系は 99.9% 目標）
- バックアップ: DB日次フル＋PITR（7日以上）

### 3.4 セキュリティ・プライバシー

- 通信は TLS 1.2+、端末ローカルDBは暗号化（服薬・健康データ）
- 健康・服薬データは**要配慮個人情報相当**として扱い、取得時に明示的同意を取得
- 家族共有は本人同意ベース、同意履歴を保存、いつでも撤回可能
- 最小権限: 見守る人は共有許可された項目のみ参照可能（サーバー側で強制）
- 管理者の健康データ閲覧はアクセスログ必須・原則マスキング
- 個人情報保護法、（将来の医療機関連携時）医療情報システムの安全管理ガイドライン（3省2ガイドライン）への準拠を検討
- 児童（一般ユーザーの未成年）の課金制限・保護者同意
- アプリストアのヘルスデータ利用ポリシー準拠（HealthKit / Health Connect）

### 3.5 運用・保守

- 監視: エラー監視（Crashlytics/Sentry）、APM、見守りアラート送信失敗の監視
- フィーチャーフラグで段階リリース
- ゲームマスタデータはアプリ更新なしで変更可能
- ログ保持: 監査ログ1年以上、アプリログ90日

### 3.6 法務・コンプライアンス チェックリスト

- [ ] 薬機法: SaMD非該当の確認（必要に応じて専門家・厚労省相談窓口へ）
- [ ] 個人情報保護法: 要配慮個人情報の同意取得フロー、プライバシーポリシー
- [ ] 景品表示法・資金決済法: ゲーム内通貨・有償アイテムの設計
- [ ] 利用規約: 「緊急通報サービスではない」「医療行為の代替ではない」旨
- [ ] キャラクター・アートのオリジナリティ確認（他社IPとの類似回避）

## 4. MVPスコープ（Phase 1）

**ゴール**: 「高齢者1人＋家族2〜3人」が1家族として毎日使える状態

含む:
- アカウント・家族招待（ACC-01〜05, SOC-01）
- 服薬管理（MED-01〜08）、歩数・運動・汎用タスク（EXE-01,02, TSK-01）
- 農園の基本ループ（GAM-01〜06, 11, 12）
- 家族農園訪問・お手伝い・スタンプ（SOC-02〜04）
- 見守りパネル・アラート（WAT-01〜04, 07〜09）
- 通知（NTF-01〜03）、最低限の管理画面（ADM-01, 02）

含まない: フレンド（家族外）交流、リアルタイム同時訪問、課金、法人向け
