# 01. 構想（コンセプト）

> ステータス: ドラフト v0.1 / 2026-10-16
> 仮タイトル: **わくわく農園**（リポジトリ名 `wakuwaku` より）

## 1. ひとことで

**「毎日の“お薬・運動”が、自分の畑を育てる水と肥料になる」**
どうぶつの森のような、ゆったりした村暮らしを楽しみながら、高齢者は無理なく服薬・運動を続けられ、離れて暮らす家族はゲームを通じて自然に見守り・交流ができる。高齢者向けの機能を前面に出しすぎず、一般の人も普通のゲームとして遊べる。

## 2. 背景と課題

| 対象 | 課題 |
|---|---|
| 高齢者本人 | 飲み忘れ・飲み過ぎ。運動が続かない。「管理されている」感覚が嫌。スマホ操作が難しい |
| 離れて暮らす家族 | 毎日電話するのは負担。でも安否や服薬状況は気になる。監視カメラ型は本人が嫌がる |
| 一般ユーザー | 習慣化アプリは続かない。癒やし系ゲームは好きだが目的がない |

既存の服薬管理アプリは「記録ツール」、見守りサービスは「監視ツール」になりがちで、**本人が楽しく続ける動機**が弱い。

## 3. 解決のアイデア

1. **現実の行動 → ゲーム内の恵み**
   - 服薬チェック → じょうろの水（作物が育つ）
   - 歩数・体操 → 肥料・道具の強化
   - 予定・家事タスク → 種・家具素材
2. **罰を与えない設計**
   - 飲み忘れても作物は枯れない（成長が止まるだけ）。高齢者に罪悪感を与えない。
   - ただし「飲み過ぎ防止」のため、同じ薬の二重チェックには確認を挟む。
3. **見守りは「遊びにいく」形で**
   - 家族は相手の農園に遊びに行き、水やり・プレゼント・スタンプを送る。
   - 服薬状況や最終ログインは、家族専用の「見守りパネル」で静かに確認できる。
   - 異常時（長時間無操作、服薬未記録が続く）のみ家族へ通知。
4. **一般ユーザーにとっては普通の農業スローライフゲーム**
   - タスク連携は「やってもいい」任意機能。習慣化アプリとして使う人も、純粋にゲームだけ遊ぶ人もOK。

## 4. ターゲットとペルソナ

| ペルソナ | 概要 | 主な利用 |
|---|---|---|
| **A. ハナさん（78）** | 一人暮らし。降圧剤など1日3回服薬。スマホはLINEと電話程度 | やさしいモードで服薬チェック、畑の世話、孫からのプレゼントを見る |
| **B. 娘のユミさん（50）** | 遠方在住、共働き。母の服薬が心配 | 見守りパネル確認、週末に母の農園へ遊びに行く、通知受信 |
| **C. 孫のソウタくん（14）** | ゲーム好き | 普通にゲームとして遊ぶ。祖母の畑にレア種をプレゼント |
| **D. 一般プレイヤー（30）** | 癒やし系ゲーム好き、運動習慣をつけたい | ふつうモードで遊ぶ。歩数・筋トレをタスク連携 |
| （将来）**E. 介護職・ケアマネ** | 複数の利用者を担当 | 法人向けダッシュボード（Phase 3以降） |

## 5. 体験の柱（デザインピラー）

1. **やさしい（Gentle）** — 大きな文字、少ない操作、罰がない、急かさない
2. **つながる（Connected）** — 家族・友人と同じ村で暮らしている感覚
3. **育つ（Growing）** — 自分の行動が目に見えて畑と村を豊かにする
4. **安心（Safe）** — 個人情報・健康情報を守る。知らない人とのトラブルを防ぐ

## 6. ゲーム世界観

- **舞台**: 小さな島の「わくわく村」。プレイヤーは自分の農園と家を持つ。
- **時間**: 現実の時刻・季節と連動（朝・昼・夕・夜、春夏秋冬の作物）。
- **住民**: どうぶつのNPC（オリジナルキャラクター）。服薬時間に声をかけてくれる「お世話係」役もいる。
- **主な遊び**: 畑づくり、収穫、料理、家と庭の模様替え、どうぶつ住民との会話、季節イベント、友だちの農園訪問。
- **注意**: 「どうぶつの森風」は雰囲気の参考であり、キャラクター・アート・UI・名称は完全オリジナルで制作する（著作権・不正競争防止法リスクの回避）。

## 7. 2つのプレイモード

| | やさしいモード | ふつうモード |
|---|---|---|
| 想定 | 高齢者・スマホが苦手な人 | 一般・若年層 |
| 文字 | 特大（最小 20sp 程度） | 標準 |
| 操作 | タップのみ・ボタン大・1画面1目的 | 自由移動・ドラッグ・複数メニュー |
| ゲーム性 | 自動移動、作業はワンタップ | 配置・クラフト・やり込み要素 |
| 読み上げ | 標準ON | 任意 |

同じアカウント・同じ世界で、いつでも切り替え可能。家族が設定を代行できる。

## 8. マネタイズ方針（案）

- 基本無料。**ガチャは採用しない**（高齢者の課金トラブル回避、景品表示法リスク回避）。
- **家族見守りプラン（サブスク）**: 見守りパネルの詳細履歴、複数人見守り、通知の高度化。
- **コスメティック販売**: 家具・服・飾り（買い切り、価格明示）。
- 将来: 自治体・介護事業者向けB2Bライセンス。

## 9. 成功指標（KPI案）

| 指標 | 目標（仮） |
|---|---|
| 高齢ユーザーの服薬チェック率（予定回数に対する記録率） | 85%以上 |
| 高齢ユーザーの30日継続率 | 60%以上 |
| 見守り家族が週1回以上相手の農園を訪問する割合 | 50%以上 |
| 一般ユーザーのD7継続率 | 30%以上 |

## 10. 重要な前提・制約

- **医療機器に該当しない範囲に留める**: 服薬の「記録」と「リマインド」のみ。用量判断、飲み合わせ判定、診断的なアドバイスはしない（薬機法上のプログラム医療機器（SaMD）該当性を避ける）。
- **服薬・健康情報は要配慮個人情報相当として扱う**: 取得・家族共有には本人の明示的同意を必須とする。
- **知らない人との自由チャットは原則禁止**: 特殊詐欺・勧誘被害を防ぐ。家族・承認済みフレンドのみ。
